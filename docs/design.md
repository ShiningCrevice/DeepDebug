# 架构与初始化决策

## 2026-10-27：基础工程

采用 Python 3.10+、`src/deepdebug` 包布局和 uv。仓库默认使用现有 Python 3.12，保持规划中的最低语言要求；其他 Python 版本尚未实际运行验证。`pyproject.toml` 是版本与依赖声明来源，CLI 从安装元数据获取版本，避免重复维护版本号。

使用标准库 argparse 构建 CLI；`deepdebug` 与 `python -m deepdebug` 共享 `main()`。初始化阶段提供帮助和版本，未知命令返回错误，无需环境变量、GPU 或模型配置。

Pydantic v2 为下一步结构化协议提供基础。pytest 用于检查安装入口，Ruff 用于静态检查和格式检查。依赖在 `uv.lock` 锁定。Streamlit、模型 SDK、BM25 和 PyTorch 在实际需要时引入，其中 PyTorch 不应成为普通快照模式的必需依赖。

## 计划的数据流（尚未实现）

CLI / Streamlit → 材料检查与脱敏 → 日志解析 → 单 Agent 控制器 → 权限校验与工具执行 → 证据登记与假设更新 → 报告校验 → Markdown / JSON。

工具返回事实，控制器维护预算与停止条件，报告必须引用登记证据。模型接口隔离供应商差异。会话使用 JSON、JSONL、Markdown 存储，首版无需数据库。

## 实现顺序

1. 初始化（完成）。
2. 依赖/解释器案例与数据协议（完成）。
3. 材料权限、日志解析、环境采集与快照、路径检查及证据登记，形成 CLI 取证闭环（完成；文档检索与其余故障种子待补齐）。
4. 模型接口、工具调度、预算和轨迹。
5. 扩展故障类别、文档检索、报告、预置验证和 Streamlit。
6. 冻结 benchmark、对照评测、复现与课程交付。

具体边界、预算与验收目标沿用项目规划。许可证尚未选择；第三方文档语料引入时须记录出处、版本、整理日期和使用条件。

## 2026-10-28：协议与首批案例

将协议分为 `schemas.py`（材料、证据、快照、报告）、`actions.py`（工具参数与判别联合）、`state.py`（会话与跨记录一致性）。CLI 可导出 JSON Schema；控制器和执行器尚未实现。详细约束与尚未实现的安全边界见 `tool-api.md`。

两个首批案例用 pydantic 作为普通 Python 依赖，通过项目环境和临时空环境构造取证差异。日志由真实 Python 进程采集，启动配置中的预期解释器由开发者设定；案例仅覆盖依赖导入。因日志和脚本相同，两例共用案例族且均属于开发集。

人工参考状态/报告集中在 `benchmark/gold/dev/`；输入位于 `benchmark/dev/*/materials/`。案例 Python 文件属于原始材料，Ruff 排除这些文件，防止格式化改变证据行号。运行时的目录权限仍需下一步实现。

## 2026-10-28：CLI 取证闭环

`collection.py` 组织固定宿主流程，CLI 只处理参数和输出。先通过 POSIX 文件描述符安全读取显式登记的材料，再关闭根目录；工具使用固定内存内容，避免后续编辑使证据行号漂移。所有链接均被拒绝，Windows 取证暂不支持。

`CollectionSession` 运行日志解析、材料读取和快照检查，写入真实工具结果及证据，失败同样进入历史。`EvidenceRegistry` 复用相同观察的 ID；状态在每次更新边界重建并校验。工具返回最多 64 KiB，文本读取限制行数和字符数。快照时间是原始采集时间，与工具执行耗时分开；首份快照失败不允许对照环境顶替。

两个开发案例已跑通固定顺序取证。后续接入模型循环、动作权限调度、预算停止、工具超时、脱敏确认、检索和完整环境采集，再开展自动诊断与修复验证。

## 2026-11-01：用户采集与工具降级

将实时采集放在显式 `snapshot` 命令，`collect` 保持导入快照模式。`tools/capture.py` 只构造固定探针，内部 `process.py` 执行单次超时、输出限制和进程回收；CLI 处理参数与退出码。可选 PyTorch/CUDA 和 GPU 探针分别记录采样时间和状态，失败不抹去已取得的 Python 身份。实时探针当前仅支持 POSIX。

路径引用由宿主显式登记，工具仅接受引用 ID。`AuthorizedRoot.inspect` 复用材料读取的目录描述符边界，只观察类型与存在性；结果标注命令运行主机与授权基准目录，保持目标快照环境独立。GPU 查询复用快照来源与原始 JSON 证据，失败写入工具历史。下一阶段补齐故障种子、文档检索，再接入模型调度与会话预算。
